# Architecture Principles

1. **Modular Design**: Transport-agnostic core with pluggable components
2. **Multi-Protocol Support**: SIP (OpenSIPS, Asterisk, FreeSWITCH), WebRTC, with Coturn/TURN
3. **Multi-Tenancy**: Secure tenant isolation with resource quotas
4. **Scalability**: Horizontal scaling from 5 to 10,000+ concurrent calls
5. **Developer Experience**: Clean APIs, MCP integration, comprehensive SDKs
